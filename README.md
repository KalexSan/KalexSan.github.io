# Portfólio — Alex Sander

Portfólio pessoal de Alex Sander Leite de Almeida, estudante de Tecnologia em Sistemas para Internet na UTFPR e desenvolvedor de software.

## Sobre o projeto

Site estático de página única que apresenta informações profissionais, experiência, formação, habilidades e projetos publicados no GitHub. A interface permite alternar entre português, inglês e espanhol, além de temas claro e escuro. Os projetos públicos são carregados pela API do GitHub.

## Tecnologias

- HTML, CSS e JavaScript, sem frameworks ou etapa de build.
- Google Fonts para as fontes Outfit e Fira Code.
- API REST do GitHub para exibir repositórios públicos.

## Como executar localmente

Abra `index.html` diretamente no navegador ou inicie um servidor local na raiz do projeto:

```bash
python3 -m http.server 8000
```

Depois, acesse <http://localhost:8000>.

## Arquivos principais

- `index.html`: estrutura, estilos e funcionalidades do portfólio.
- `avatar_profile.png`: imagem de perfil utilizada no site.
